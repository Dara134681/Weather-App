# Weather-APP

To use the weather calculator enter the country you want to find out the weather about ( make sure it spelled correctly ) 
And it will give you all the information on the country's weather and the following days
Enjoy!!



🌦️ Weather‑App

A simple and elegant weather application that provides real‑time weather updates and forecasts for any country.


🚀 Features
- 🌍 Search weather by country name  
- 🌡️ Displays temperature, humidity, and wind speed  
- 📅 Shows forecast for upcoming days  
- 💻 Clean and responsive interface  


🧭 How to Use
1. Enter the **country name** you want to check.  
2. Make sure the spelling is correct.  
3. Click **Get Weather**.  
4. The app will display:
   - Current temperature  
   - Weather condition (sunny, cloudy, rainy, etc.)  
   - Forecast for the next few days
